# Triage Labels

Die Skills verwenden fuenf kanonische Triage-Rollen. In diesem Repository bleiben die Label-Namen identisch.

| Label in mattpocock/skills | Label in unserem Tracker | Bedeutung |
| --- | --- | --- |
| needs-triage | needs-triage | Maintainer muss das Issue einordnen |
| needs-info | needs-info | Es fehlen Informationen vom Reporter |
| ready-for-agent | ready-for-agent | Voll spezifiziert, bereit fuer AFK-Agent |
| ready-for-human | ready-for-human | Muss von einem Menschen umgesetzt werden |
| wontfix | wontfix | Wird nicht umgesetzt |

Wenn ein Skill eine Rolle nennt, verwende das entsprechende Label aus dieser Tabelle.
